# 🚀 AI Crypto Platform

An end-to-end AI-powered cryptocurrency data platform built with Python that collects live market data, processes it through a modular data pipeline, stores it efficiently, and presents insights through an interactive dashboard.

This project is designed to combine **Data Engineering**, **Cloud Computing**, and **Artificial Intelligence** into a single production-style application while continuously evolving with new features.

---

## ✨ Features

* 📈 Real-time cryptocurrency market data
* 🤖 AI-powered market insights
* 🗄️ PostgreSQL database integration
* 📊 Interactive Streamlit dashboard
* 🧹 Data cleaning and preprocessing
* 🔄 Modular ETL pipeline
* 📦 Scalable project architecture
* ☁️ Future AWS deployment

---

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/zypherpython/AI-Crypto-Platformm.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
